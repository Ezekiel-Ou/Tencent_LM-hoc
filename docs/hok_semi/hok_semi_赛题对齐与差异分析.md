### 3.3 小兵排序规则（关键差异）

**hok_semi（错误）**：
```python
# 按距离排序
soldiers = sorted(soldiers, key=lambda s: math.dist(s.position, self.pos))
```

**本次赛题（正确）**：
```python
# 按runtime_id升序排序
soldiers = sorted(soldiers, key=lambda s: s.runtime_id)
```

**为什么重要？**
- 动作协议中，target head的第3~6维对应"敌方小兵1~4"
- 如果排序不一致，模型会选择错误的攻击目标
- agent_diy已修正

## 总结

### 核心发现

1. **80%可复用**：网络架构、PPO算法、特征编码框架、动作空间完全相同
2. **20%需修改**：主要是英雄specific的配置（buff、mark、权重）
3. **关键陷阱**：小兵排序、血包计算、kill权重是容易遗漏的bug
4. **建议路径**：基于hok_semi框架，替换hero-specific配置，修正已知bug
