# 特征工程全面重构方案

## 核心设计原则

| 原则 | 说明 |
|------|------|
| **对角线坐标系** | 地图沿对角线分布，用 `(u,v)` 替代 `(x,z)` |
| **分层精度** | 近距离精细（500格），远距离粗略（5000格） |
| **硬编码锚点** | 塔、基地位置直接给距离，不再让模型推断 |
| **移除浪费** | 印记移出通用单位，英雄专属buff动态选择 |
| **补齐缺失** | 己方子弹、小兵子弹、塔攻击范围、血包精确位置 |
| **修复截断** | HP/EP/CD范围覆盖实际最大值 |

---

## 一、坐标系变换

```python
import math
SQRT2_INV = 1.0 / math.sqrt(2)

def transform(x, z):
    u = (x + z) * SQRT2_INV   # 推进轴：己方基地(-) → 敌方基地(+)
    v = (z - x) * SQRT2_INV   # 横向轴：范围很小
    return u, v
```

**硬编码锚点（u轴坐标）**：
```python
SELF_BASE_U   = -56569   # (-80000 * SQRT2_INV)
SELF_TOWER_U  = -18385   # (-26000 * SQRT2_INV)
CENTER_U      = 0
ENEMY_TOWER_U = 18385    # (26000 * SQRT2_INV)
ENEMY_BASE_U  = 56569    # (80000 * SQRT2_INV)
```

## 二、位置编码（替代原来的125维）

### 设计：三层混合编码

```python
# 第1层：精细相对位置（贴身战斗、走位）
u_close:  41维 one-hot, 范围±10000, 格500
v_close:  21维 one-hot, 范围±5000,  格500（v范围小）
close_dist: 1维连续值

# 第2层：远距离推进（塔、基地）
u_far:    21维 one-hot, 范围±50000, 格5000

# 第3层：硬编码锚点距离
anchors:   8维
  [0] dist_to_self_tower   / 50000.0   # 到己方塔
  [1] dist_to_enemy_tower  / 50000.0   # 到敌方塔
  [2] dist_to_self_base    / 100000.0  # 到己方基地
  [3] dist_to_enemy_base   / 100000.0  # 到敌方基地
  [4] in_self_tower_range  (0/1)       # 是否在己方塔攻击范围
  [5] in_enemy_tower_range (0/1)       # 是否在敌方塔攻击范围
  [6] in_self_base_zone    (0/1)       # 是否在己方基地区域
  [7] in_enemy_base_zone   (0/1)       # 是否在敌方基地区域

# 总位置编码：41 + 21 + 1 + 21 + 8 = 92维
```

**覆盖验证**：
- 塔距离（~18000）：u_close完全覆盖
- 基地距离（~56000）：u_far完全覆盖
- 泉水（100000）：u_far边界处理

## 八、子弹特征（全面重构）

### 设计目标
- ✅ 编码**己方子弹**（判断技能是否命中）
- ✅ 编码**敌方小兵子弹**（不再忽略）
- ✅ 编码**威胁度**

### 每个子弹的编码

```python
bullet_category: 5维 one-hot
  [0] 己方英雄子弹
  [1] 己方小兵子弹
  [2] 敌方英雄子弹
  [3] 敌方小兵子弹
  [4] 敌方防御塔子弹

bullet_slot: 5维 one-hot
  [0] 普攻（ SLOT_SKILL_0 ）
  [1] 技能1（ SLOT_SKILL_1 ）
  [2] 技能2（ SLOT_SKILL_2 ）
  [3] 技能3（ SLOT_SKILL_3 ）
  [4] 其他（ SLOT_SKILL_4+ ）

bullet_rel_pos: 3维 连续值
  [0] rel_u / 10000.0   # 相对推进位置
  [1] rel_v / 10000.0   # 相对横向位置
  [2] dist / 10000.0    # 直线距离

bullet_threat: 1维
  [0] threat_score       # 1.0=极近(<1000), 0.5=中等(<3000), 0.0=远

DIM_BULLET = 5 + 5 + 3 + 1 = 14维
```

### 数量分配（20个）

```python
BULLET_MAX_NUM = 20

# 分配：
# 0-4:   敌方英雄子弹（5个）
# 5-7:   敌方小兵子弹（3个）← 新增
# 8-10:  己方英雄子弹（3个）← 新增
# 11-13: 己方小兵子弹（3个）← 新增
# 14:    敌方防御塔子弹（1个）
# 15-19: 保留/填充

# 模型中按类别max pooling：
# 敌方英雄：5个 → MLP → max pool → 32维
# 敌方小兵：3个 → MLP → max pool → 32维 ← 新增分支
# 己方英雄：3个 → MLP → max pool → 32维 ← 新增分支
# 己方小兵：3个 → MLP → max pool → 32维 ← 新增分支
# 敌方塔：1个 → MLP → 32维

DIM_BULLETS = 14 × 20 = 280维
# 原来1300维，节省1020维
```

## 十、关键改进总结

| 问题 | 原设计 | 新设计 |
|------|--------|--------|
| 位置编码 | x/z分别，塔距离截断 | **对角线u/v，分层精度，锚点硬编码** |
| HP截断 | MAX=2400，塔12000被挤到最后一档 | **非均匀分档，覆盖15000** |
| EP截断 | MAX=240，实际630+ | **非均匀分档，覆盖1000+** |
| CD截断 | MAX=10秒，长CD不够 | **分档到30秒** |
| 印记浪费 | 小兵/塔/河蟹都有15维印记（永远是0） | **移到英雄专属** |
| BUFF浪费 | 对方英雄20维永远是0 | **动态选择相关buff** |
| 小兵行为 | 只有"死"和"攻击路径" | **增加"打英雄"、"打塔"** |
| 塔攻击范围 | 不知道边界在哪 | **直接编码边界距离** |
| 血包位置 | 只知道"有无" | **编码相对位置** |
| 己方子弹 | 完全不编码 | **编码3个己方英雄+3个己方小兵子弹** |
| 敌方小兵子弹 | 完全丢弃 | **编码3个** |
| 子弹维度 | 130维×10=1300 | **14维×20=280** |

## 十一、实施建议

### 文件修改清单

1. **`conf/conf.py`**：
   - 所有DIM_*参数重新计算
   - 新增坐标变换参数
   - HP/EP/CD范围扩大
   - BUFF动态选择逻辑

2. **`feature/feature_process.py`**：
   - `_process_position`：重写为对角线坐标系+三层编码
   - `_process_unit`：去掉印记，只保留位置+HP
   - `_process_hero`：增加动态BUFF选择
   - `_process_soldier`：增加行为状态
   - `_process_tower`：增加血包位置+攻击边界
   - `_process_bullet`：全新设计（14维）
   - `_split_enemy_bullets`：扩展为己方+敌方小兵子弹

3. **`model/model.py`**：
   - 子弹处理分支增加（敌方小兵、己方英雄、己方小兵）
   - 输入维度调整
